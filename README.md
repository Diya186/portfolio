# Diya — Interactive Universe Portfolio

> A portfolio that feels less like a résumé and more like entering someone's mind.

**Live site → [diya186.github.io/portfolio](https://diya186.github.io/portfolio)**

---

## What is this?

This is my personal portfolio, built as a fully interactive story-driven experience. Instead of a traditional navigation-based site, visitors are guided through an intro sequence and then choose which version of me they want to explore.

No frameworks. No build tools. Pure HTML, CSS, and JavaScript — deployed on GitHub Pages.

---

## The Experience

The intro plays like an opening sequence:

1. A blinking cursor appears on a black screen
2. Three questions type themselves out — *who am i? what am i? why am i?*
3. Then, slowly: **hi, i'm diya.**
4. `hi,` and `diya.` fade away — `I'm` slides to the left
5. Words roll beside it: *a creator. a coder. a dreamer. a hopeless romantic. still figuring it out.*
6. Everything disappears — **"I'm here to make a difference."**
7. Four pixel-art characters appear — each one a different version of me

---

## The Four Worlds

| World | Character | What's inside |

| **CODE** | Coder Diya | Projects, cybersecurity labs, ML work, Android apps |
| **CREATE** | Creator Diya | Reels, edits, brand work, content creation |
| **WRITE** | Writer Diya | Personal essays, poems, reflections |
| **EXPLORE** | Just Diya | Hobbies, things I love, the human stuff |

## Built With

- HTML5 Canvas (stars, animations)
- CSS (custom animations, Cormorant Garamond + Plus Jakarta Sans + JetBrains Mono)
- Vanilla JavaScript (no libraries, no frameworks)
- Web Audio API (subtle sound design)
- GitHub Pages (deployment)
